# The Home Window
{: .no_toc }

**Tools → Decnet Games → GlueKit** opens GlueKit Home. Everything GlueKit does in the Editor lives in this one window — there are no orphaned feature windows.

## Welcome

The welcome block carries the one-click setup and its verification: run [setup]({{ site.baseurl }}/docs/one-click-setup/) once, and the window confirms the state of your install.

## Leg Status

Leg Status answers "what state is my glue in?" at a glance — one line per system, so a broken or unconfigured leg is visible before you go looking for it.

## The system sections

- **Settings** — the active settings profile and menu generation state. See [The Settings System]({{ site.baseurl }}/docs/settings-system/).
- **Input Rebinding** — the rebind profile and binding counts. See [Key Rebinding]({{ site.baseurl }}/docs/key-rebinding/).
- **Save Slots** — the save data root and the state of every slot, manual and autosave. See [Save Slots]({{ site.baseurl }}/docs/save-slots/).
- **Debug Console** — the console's audience setting and its release-strip state. See [The Debug Console]({{ site.baseurl }}/docs/debug-console/).
- **Samples** — the GlueKit Playground sample and its first-run checklist. See [The Playground Sample]({{ site.baseurl }}/docs/playground/).
