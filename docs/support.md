# Support
{: .no_toc }

## Email

**support@decnetgames.com** — the support address for GlueKit and every Decnet Games product. When you write, include what GlueKit Home shows: the Leg Status section and the relevant system's section (active profile, slot state, console strip state) make a report answerable instead of speculative.

## Community

- **Discord** — [discord.gg/P9wepz7NBW](https://discord.gg/P9wepz7NBW)
- **Other Decnet Games assets** — [the publisher page](https://assetstore.unity.com/publishers/118262) on the Unity Asset Store.

## Before you write

- [Troubleshooting]({{ site.baseurl }}/docs/troubleshooting/) covers the states GlueKit reports about itself: a leg not ready, an unavailable save, a flagged unbound action, and the console's deliberate absence from release builds.
- [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/) is the boundary list — if the thing you need is on it (save migration, cloud sync, a 2022.3 build), it is a v1 boundary, not a bug.
