# GlueKit-DOC

Documentation site source for **GlueKit — Settings, Controls, Save Slots & Debug Console for Unity 6** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/GlueKit-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Home Window, One-Click Setup, The Settings System, Graphics Presets & Display, Key Rebinding, Save Slots, Autosave, Load Validation, The Debug Console, Console Commands, Stripping the Console from Release Builds, The Playground Sample, What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- No `assets/` media: this tree ships zero screenshots by design (the MergeGuard-DOC precedent — text-first documentation). Screenshots join the tree only after the product's real Editor capture session exists; documentation never ships invented imagery.

GlueKit itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
