# Quick Start
{: .no_toc }

The Playground is the quick start. It is a small walkable yard with a checkpoint arch, a locked door, and a prompt card listing five things to try — one per system, plus the moment they combine.

## The path

1. Open **Tools → Decnet Games → GlueKit** and run the [one-click setup]({{ site.baseurl }}/docs/one-click-setup/).
2. Import the **GlueKit Playground** sample from the Samples section of GlueKit Home and press Play.
3. **Lower the Music Volume.** Open the settings menu, drop the Music Volume slider, and hear it fall — the settings system, live. See [The Settings System]({{ site.baseurl }}/docs/settings-system/).
4. **Rebind Jump to F.** Open Controls, capture a new binding for Jump — F instead of Space — and jump with F. If you capture a key another action already uses, the panel names the conflict and offers Swap, Replace, or Cancel. See [Key Rebinding]({{ site.baseurl }}/docs/key-rebinding/).
5. **Walk through the checkpoint.** The autosave slot appears with its timestamp and thumbnail — a slot manual saves can never overwrite. See [Autosave]({{ site.baseurl }}/docs/autosave/).
6. **Save "First run" into Slot 1.** A manual save, renamed in the slot panel. See [Save Slots]({{ site.baseurl }}/docs/save-slots/).
7. **Open the console and type `gluekit.give key`.** Then open the locked door. See [The Debug Console]({{ site.baseurl }}/docs/debug-console/).

That sequence is the demo, the onboarding, and the product: all four systems working together in one session, in the sample that ships in the package.
